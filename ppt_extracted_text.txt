CONCEPT 1: MULTIVARIATE ANALYSIS
PHYSICS-BASED VALIDATION
• 
Inter-variable Links: 
Atmospheric parameters (temperature, pressure, relative humidity) are physically correlated and follow meteorological laws.
• 
Univariate Blindspot: 
Univariate systems only analyze one sensor at a time. They miss joint relationships where values are normal individually but impossible in combination.
• 
Correlation Checking: 
SkyGuard models the correlation matrix. If pressure drops sharply while temperature climbs during high humidity, it flags a multivariate anomaly.
• 
False Alarm Reduction: 
This physics-aligned modeling prevents extreme, genuine weather anomalies from being falsely categorized as equipment failure.

CONCEPT 2: ISOLATION FOREST
ISOLATING ANOMALIES
• 
Algorithm Design: 
Isolation Forest is an unsupervised algorithm that isolates anomalies instead of profiling normal data points.
• 
Random Partitioning: 
The dataset is recursively partitioned by randomly selecting a feature and a split value.
• 
Path Length Principle: 
Anomalies require far fewer partitions (shorter path lengths) to isolate because they lie away from dense clusters.
• 
Performance Benefit: 
Provides immediate, low-latency detection of sharp sensor spikes and sudden out-of-bounds readings.

CONCEPT 3: AUTOENCODER RECONSTRUCTION
RECONSTRUCTION-BASED DETECTION
• 
Core Model: 
A neural network consisting of an Encoder (data compression) and a Decoder (data reconstruction).
• 
Training Paradigm: 
The model is trained entirely on historical, clean observation streams (normal weather patterns).
• 
Anomaly Metric: 
When presented with normal readings, the reconstruction error is low. If readings contain anomalies (e.g. sensor drift), the error spikes.
• 
Primary Use Case: 
Highly effective at identifying gradual sensor degradation and long-term calibration drift.
